# Climate Intelligence & Sustainability Analytics Platform

An end-to-end climate analytics platform built with Python, Pandas, NumPy, Plotly, Streamlit, Scikit-learn, and Google Gemini API.

## Project Overview

This project analyzes climate, air-quality, and carbon-emission data to identify trends, visualize environmental indicators, evaluate climate risks, and support sustainability-oriented decision making.

The platform combines data analysis, visualization, machine learning, scenario analysis, and AI-assisted insights in an interactive Streamlit application.

## Key Features

- Climate and temperature trend analysis
- Air-quality analysis
- CO2 and carbon-emission analysis
- Climate risk analysis
- Renewable-energy analysis
- Interactive dashboards and visualizations
- Sustainability scenario analysis
- Baseline machine-learning forecasting
- AI-assisted explanations using Google Gemini
- Data filtering and interactive KPIs
- Exportable analytical results

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Scikit-learn
- Google Gemini API
- Git & GitHub
